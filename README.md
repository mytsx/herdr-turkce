# Herdr Türkçe Kılavuz

[Herdr](https://herdr.dev/) için resmî olmayan Türkçe kısayol kartı, `hc` komutları, taktikler ve altın kurallar.

**Sayfa:** https://mytsx.github.io/herdr-turkce/

Herdr 0.1.15 ve hc 0.1.21'in yerleşik kılavuzlarından (`hc --skill`, `herdr-app --skill`, `~/.config/herdr-app/AGENTS.md`, `keys.json`) derlendi.
